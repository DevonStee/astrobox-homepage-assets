# Brin · AstroBox homepage assets

Static media for Brin’s AstroBox creator homepage: background, animated showcase, and collection covers.

This is an asset hosting repository, not a published AstroBox watch-face resource. It has no watch-face packages, resource listing manifest, or AstroBox review submission.

## Media

- `media/profile-dual-showcase-20261019-v1.webp` — animated homepage showcase.
- `media/profile-red-background-20261019-v1.png` — red homepage background.
- `media/profile-boarding-pass-20261019-v1.png` — “拿好登机牌” collection cover.
- `media/profile-time-simply-20261020-v3.png` — “时间，简单就好” collection cover, TIME SIMPLY only, in a playful rounded font.

`assets.json` records the SHA-256 digest and size of each file. AstroBox references the raw image URLs directly.

## Official platform icons

`media/afdian-official-icon.png` is the unchanged official Afdian icon referenced by [afdian.com](https://afdian.com/), downloaded from its official CDN. Used for the creator support button.

`media/xiaohongshu-official-icon-180.png` is the unchanged 180 × 180 official Xiaohongshu apple-touch icon referenced by [xiaohongshu.com](https://www.xiaohongshu.com/). It replaces the 32px favicon in the homepage button.
